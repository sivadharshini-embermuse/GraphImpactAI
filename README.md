# GraphImpact AI

GraphImpact AI: A Machine Learning-Based Intelligent Change Impact Prediction and Software Maintenance System.

## Architecture Overview
- **frontend**: React.js, Tailwind CSS, Axios, React Router UI layer.
- **backend**: Node.js, Express.js, Multer API gateway & MongoDB controller.
- **analyzer**: Python Tree-sitter AST parser, NetworkX Repository Knowledge Graph builder, and Scikit-learn Random Forest ML Change Impact Prediction engine.
- **storage**: Extracted repository codebases, graph JSON caches, predictions, and analysis reports.
- **uploads**: Temporary staging area for raw Original ZIP and Modified ZIP repository uploads.
